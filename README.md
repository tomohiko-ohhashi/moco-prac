# もこぷらっ！ − モールス練習アプリ(moco-prac)

スマホ最優先のモールス信号練習アプリです。欧文(国際モールス)と和文(カタカナ)の両方に対応し、
**聞き取り練習(受信)/打鍵練習(送信)/符号表・変換ツール** をひとつの画面で切り替えて使えます。

- 純粋な静的サイト(HTML / CSS / vanilla JS)。ビルドも npm 依存もありません
- Web Audio API による正確なタイミングの再生と低遅延サイドトーン
- PWA 対応: ホーム画面に追加でき、オフラインでも動作します
- ダークテーマ、大きなタッチターゲット、iPhone / Android のブラウザ向けに調整

## 使い方

ヘッダー右上の **欧文 / 和文** で符号モードを切り替えます。画面下のタブで機能を選びます。

### 🎧 聞き取り(受信練習)
1. レベルを選ぶ(欧文はコッホ法 LCWO 順の 40 段階、和文は五十音グループの 12 段階)
2. 「セッション開始」で符号が再生されます。画面上のボタンで答えて「判定」
3. ○/× と正解・符号が表示されます。「再生」で聞き直し、「次へ」で次の問題
4. セッション終了時にスコアと苦手文字が表示され、正答率 90% 以上で「レベルアップ」できます

画面上の `wpm` ステッパは実効速度(Farnsworth: 文字間のみを遅くする)です。文字速度・出題数・1問の文字数は設定タブで変えられます。

### 🔘 打鍵(送信練習)
- 大きなパッドをタップ / 長押しして打鍵します(PC は Space キー)。押下が 2 単位未満なら短点、以上なら長点
- 間隔をあけると文字が確定し、さらに長くあけると語区切りになります
- **自由打鍵**: 打った符号がそのまま文字にデコードされます(和文は「カ」+「゛」→「ガ」に合成)
- **課題**: 出題された文字を打鍵し、自動で ○/× を判定します。「自動」をオンにすると、お題が変わるたびに符号を再生します(設定タブの「お題を自動再生」と連動)
- **ツリー**: モールスの二分木(左＝短点・ 右＝長点−)を表示し、打鍵するたびに現在位置が光り、文字が確定するとそのノードがフラッシュします。市販の「モールスツリー」練習ボードと同じ感覚で符号の構造を体で覚えられます。ノードをタップするとその符号を再生。欧文は A–Z(4 要素まで)、和文はカナ+゛゜ー(5 要素まで)を表示。和文は「・側 / −側」の半分ずつ表示し、最初の打鍵で自動的に切り替わります
- 打鍵タブは 3 モードとも画面内に収まるレイアウト(パッドが残りの高さを埋め、横画面は左右 2 カラム)。ダブルタップ拡大・長押しメニューは出ません
- **ゲーム**: タイピングゲーム風の練習。スタート → 3 秒カウントダウン → 制限時間(30 / 60 / 120 秒)内に表示される単語を 1 文字ずつ打鍵します。正解で次の文字へ、ミスは赤くフラッシュして同じ文字をやり直し。各文字の下にトンツー(・−)を表示します。単語は現在レベルの文字だけで組める語(欧文: 一般的な英単語約 450 語+CQ・PARIS などの無線用語、和文: ラジオ・デンシン など)から出題し、足りなければレベルの文字からランダム生成。終了後に文字数・ミス・正答率・CPM と自己ベストを表示します。出題は「単語 / ランダム5文字」を切替でき、「・− 表示」をオフにすると文字だけになります(慣れてきたら思い出す練習に)。文字ごとの統計から苦手な文字を含む語が優先して出題されます
- 設定で「二つボタン(・ / −)」方式や、判定速度、「ゆっくり確定」に変更できます

### 📖 符号表・変換
- テキスト ⇄ モールスを双方向にライブ変換。モールス入力は `・−` でも `.-` でも受け付けます
- ▶ 再生で音を鳴らし、再生中の文字をハイライトします
- 符号表のセルをタップするとその符号が鳴ります(和文は五十音・濁点/記号・ホレ/ラタ)

### ⚙️ 設定
音(周波数 400–1000 Hz、音量)/ 聞き取り(文字速度・実効速度・出題数・出題文字数)/ 打鍵(判定速度・入力方式・ゆっくり確定)/ 画面(スリープ防止)/ 統計の表示とリセット。設定と学習統計は端末内(localStorage)に保存されます。

## GitHub Pages で公開する

このリポジトリはルートに `index.html` を置き、すべて相対パスで参照しているため「Deploy from a branch」でそのまま公開できます。

1. GitHub のリポジトリページで **Settings → Pages** を開く
2. **Build and deployment → Source** で **Deploy from a branch** を選ぶ
3. **Branch** で `develop`(または公開したいブランチ)と `/ (root)` を選び **Save**
4. 数分後に `https://<ユーザー名>.github.io/moco-prac/` で公開されます

公開後、iPhone は Safari で開き「共有 → ホーム画面に追加」、Android は Chrome の「ホーム画面に追加 / インストール」でアプリのように使えます。

## 開発・テスト

```bash
# ロジックのセルフテスト(依存ゼロ)
node test/run-tests.js

# ローカルで動かす(Service Worker を使うには http(s) 配信が必要)
npx http-server -p 8080 .
# → http://localhost:8080/
```

`index.html` を `file://` で直接開いても動作します(この場合 Service Worker は登録されません)。

### 構成

| パス | 内容 |
| --- | --- |
| `index.html` / `css/style.css` | SPA 本体(4 タブ)とスタイル |
| `js/morse-data.js` | 欧文・和文の符号表、コッホ順、五十音レベル定義 |
| `js/morse-codec.js` | テキスト正規化・encode/decode(濁点合成)・再生タイムライン計算 |
| `js/morse-tree.js` | モールスツリー(二分木)の構築・座標計算と SVG 描画 |
| `js/typing-game.js` | タイピングゲーム(出題語の選定・スコア計算・状態機械) |
| `js/keyer.js` | 打鍵の長短・間隔判定ステートマシン |
| `js/storage.js` / `js/audio.js` / `js/ui-common.js` | 保存・音・UI 共通 |
| `js/rx-trainer.js` / `js/tx-trainer.js` / `js/reference.js` / `js/settings.js` | 各画面 |
| `js/app.js` | 起動処理・Service Worker 登録 |
| `sw.js` / `manifest.webmanifest` / `icons/` | PWA |
| `test/run-tests.js` | セルフテスト |

上記 3 つのロジックファイルは Node でもブラウザでも読み込めます(テストは Node で実行)。

### ファイルを更新したとき

Service Worker は cache-first で動作するため、公開後にファイルを更新したら `sw.js` の `CACHE_VERSION` を上げてください。古いキャッシュは次回起動時に削除され、新しいファイルが取得されます。

## スマホ実機チェックリスト

- **iPhone(Safari)**
  - マナーモード(消音スイッチ ON)では Web Audio の音が鳴りません。音が出ないときはまずスイッチと音量を確認
  - 「共有 → ホーム画面に追加」でフルスクリーン起動できること、機内モードでも開けること
  - 打鍵パッドのサイドトーンの遅延が気にならないこと(押下中はゲインをランプするだけで低遅延)
  - 画面を一度スリープさせて戻った後も再生できること(AudioContext の再開)
- **Android(Chrome)**
  - 「ホーム画面に追加 / アプリをインストール」が出ること
  - 二つボタン方式でバイブレーションが動くこと
  - 設定の「スリープ防止」が有効になること(Wake Lock API)
